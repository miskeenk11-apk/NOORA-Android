# NOORA V1 — Real Voice Conversation Foundation

Approved NEXT stage.

Implemented foundation:
- Android SpeechRecognizer input
- Urdu/English language selection boundary
- Android Text-to-Speech output
- Conversation coordinator
- Online/offline-aware response path
- Memory hooks for last user text and NOORA reply

Important:
- This is the device voice pipeline foundation, not a claim that a cloud AI provider is already connected.
- A secure provider gateway should be added next; API keys must not be embedded in the APK.
- Android permissions remain user-controlled.
