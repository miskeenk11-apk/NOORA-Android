# NOORA — Advanced Phone Control Foundation

This stage adds an Android Accessibility Service foundation for user-enabled phone interaction.

## Supported foundation
- Back
- Home
- Recent Apps
- Tap/Swipe gesture primitives exposed by the service for future command parsing
- Window/content access is enabled for future UI-element interaction

## Important
The user must explicitly enable **NOORA Phone Control** in Android Accessibility settings. NOORA does not bypass Android security or silently enable the service.

This is a foundation: natural-language coordinate selection, robust UI-element targeting, and text typing can be expanded in later stages after real-device testing.
